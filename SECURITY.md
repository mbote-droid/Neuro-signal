# Security policy

Report vulnerabilities privately through GitHub's "Report a vulnerability"
(Security tab) rather than a public issue. Include a minimal file or command
that reproduces the problem.

Scope: parsing of untrusted recordings, leakage of identifiable data into
outputs, HTML injection into reports, handling of API credentials, and the
claim checker accepting false statements. See docs/THREAT_MODEL.md.

This is research software, not a medical device. Do not use it for clinical
decisions.
